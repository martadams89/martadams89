## 🔧 What I Do

### 🏗️ Infrastructure Automation
Crafting efficient, repeatable workflows using **Ansible**, **Puppet**, and **Terraform** to eliminate manual toil and ensure consistency across environments.

### 🐳 Self-Hosting & Containerization
Running Docker containers on Ubuntu VMs (Proxmox) and Oracle Cloud's ARM servers. Always experimenting with new self-hosted services and optimizing resource utilization.

### 🐧 Server Administration
Deep expertise in Linux (CentOS, Oracle Linux, RHEL, Ubuntu) and Windows Server environments—from load balancers (HAProxy) to monitoring stacks (Zabbix, ELK).

### 🔒 Security & Compliance
Active involvement in **ISO27001** and **SOC2** compliance audits, vulnerability management, remediation workflows, and security automation.

### 🤝 Open-Source Contributions
I occasionally contribute to projects on GitHub and maintain several pet projects exploring infrastructure automation and cloud-native technologies.
